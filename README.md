# SPMB Ceria

Bangun aplikasi web Sistem Penerimaan Siswa Baru (SPMB) lengkap berdasarkan spesifikasi pengguna. Gunakan Bahasa Indonesia untuk seluruh UI, desain modern profesional responsif, dan prioritaskan alur sederhana untuk wali murid. Aktifkan Lovable Cloud terlebih dahulu untuk autentikasi Google wajib bagi wali murid, peran operator, database, storage dokumen, keamanan/RLS, audit log, QR, dan proses seleksi. Implementasikan landing page, pendaftaran stepper lengkap, validasi, upload PDF/PNG dengan preview/progress/status dan kompresi terjaga, dashboard wali murid/operator, pengaturan jurusan/kuota/kriteria/bobot/jadwal WIB, scoring/ranking, pengumuman terjadwal, kartu/bukti cetak A4 dengan QR, scan/verifikasi daftar ulang, tombol salin, serta pembatasan akses dan waktu sesuai seluruh aturan yang diberikan. Jangan gunakan data siswa contoh yang menyerupai data asli; gunakan placeholder atau state kosong yang informatif.
